# 인생미정

출생부터 첫 직업을 고르기까지, 선택으로 한 사람의 인생을 써 내려가는 한국어 비주얼노벨입니다. React, TypeScript, Vite로 만들었고 브라우저에서 게임 규칙과 저장을 처리합니다.

## 실행

Node.js 20.19+ 또는 22.12+ 환경에서 실행합니다.

```sh
npm ci
npm run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 엽니다. 의존성 설치 후에는 게임 실행에 외부 API, 서버 계정, 폰트 다운로드가 필요 없습니다. 최신 Chrome·Edge·Safari·Firefox의 CSS 스코프 지원을 사용합니다.

```sh
npm test
npm run build
npm run preview
```

빌드 결과는 `dist/`에 생성됩니다. Windows 작업 드라이브에서 Vite의 재귀 삭제가 실패해 빌드가 기존 산출물을 자동으로 비우지 않도록 설정했습니다. 이전 빌드 파일까지 제외하고 배포할 때는 새 출력 폴더에 빌드할 수 있습니다.

## 플레이와 구현 범위

| 콘텐츠 | 수량 |
| --- | ---: |
| 랜덤·조건부 사건 | 100 |
| 유아기 / 초등 / 중등 / 고등 / 대학 / 대학원 / 공통·특수 | 10 / 15 / 15 / 25 / 15 / 10 |
| 선천적 특성 | 30 (희귀도별 10) |
| 후천적 특성 | 22 |
| 직업 엔딩 | 37 (일반 실무·진로 탐색 포함) |
| 업적 | 34 |
| 관계 인물 / 생활 활동 | 9 / 13 |

세 라운드에 걸쳐 선천적 특성을 고릅니다. 유아기에는 활동을 두 개, 이후에는 세 개까지 선택할 수 있습니다. 꾸준히 한 활동은 후천적 특성과 숙련도를 만들며, 누적 반복에 따라 성장이 둔화됩니다. 고정 일정과 조건에 맞는 랜덤 사건은 대기열에서 개별적으로 처리합니다.

고3 11월에 수능을 볼지 선택합니다. 내신·활동 기반 경로와 수능 기반 경로가 있고, 각각의 전공 및 대학원 진학 조건은 화면에서 확인할 수 있습니다. 대학과 대학원 과정의 요건 미충족 시 보충 이수·논문 보완으로 마무리할 수 있습니다. 전문 자격·채용이 필요한 직업은 전공과 숙련도를 충족한 뒤 별도 준비를 선택해야 합니다. 일부 장기 수련은 게임 내 전문 과정 선택과 엔딩 연령으로 압축했습니다.

직업을 고르면 실제 선택 로그에서 인생 회고를 생성합니다. 도감에는 발견 여부와 달성 횟수, 최초 기록이 남고 인생 기록에서 각 회차를 따로 열 수 있습니다. 회차는 활동 처리 직후와 사건 선택 직후를 포함해 자동 저장됩니다. 현재 회차와 업적·회고 프로필은 독립 필드로 관리합니다. 로컬 저장은 둘을 함께 기록해 엔딩 확정 도중 양쪽 기록이 어긋나지 않게 합니다. 손상된 데이터는 직전 정상 스냅샷으로 복구하며 두 스냅샷이 모두 손상되면 새 상태로 시작합니다.

## 프로젝트 구조

| 경로 | 용도 |
| --- | --- |
| `src/game/` | 상태 타입, 학사 일정 설정, 사건·성장 엔진, 직업 판정, 회고 |
| `src/data/` | 활동, NPC, 특성, 사건, 직업, 업적, 일러스트 목록 |
| `src/app/` · `src/screens/` · `src/components/` | 진입점과 React 게임 화면 |
| `src/services/storage.ts` | 저장 인터페이스, 로컬 저장, 버전 검증 및 복구 |
| `src/styles/game.css` | 게임 루트에 스코프된 스타일 |
| `public/assets/` | 타이틀, 배경, 캐릭터, 전용 사건, 엔딩 그림 |
| `tests/life.test.ts` | 콘텐츠 검증, 결정론적 경로 시뮬레이션, 저장 복구 테스트 |

단계별 시기·최대 활동 수·확률은 `src/game/config.ts`에서, 기본 활동 수치는 `src/data/activities.ts`에서 조정합니다. 고정 학사 일정은 `src/game/schedule.ts`에 있고, 고정 사건 내용과 진학 선택지는 `src/data/events/fixed.ts`에 있습니다. 신규 랜덤 사건은 해당 단계 모듈에 행을 추가하고 `src/data/events/index.ts`에 조건을 추가합니다.

## 커뮤니티에 추가하기

**독립 경로로 호스팅**하려면 `dist/` 내용을 커뮤니티의 `/minigames/life-undecided/` 아래에 배치합니다. 기본 빌드는 상대 경로를 사용합니다. 절대 경로가 필요한 구성에서는 빌드 환경 변수 `VITE_GAME_BASE=/minigames/life-undecided/`를 지정합니다. 화면 전환은 게임 내부 상태로 처리하므로 별도의 화면별 라우팅 규칙은 필요 없습니다.

**기존 React 페이지에 삽입**하려면 게임 소스 모듈을 프로젝트에 포함하고 `LifeGame`을 렌더링하거나 `mountLifeGame`을 사용합니다. 독립 게임의 `public/assets/`를 호스트의 정적 경로로 복사합니다.

```ts
import { mountLifeGame } from './life-undecided/src/app'

const unmount = mountLifeGame(document.querySelector('#life-game')!, {
  assetBase: '/minigames/life-undecided/assets/',
  userId: communityUserId,
  onEnter: () => recordGameEntry(),
  onExit: () => navigateAway(),
})
// 호스트 페이지에서 제거할 때 unmount()를 호출합니다.
```

`userId`는 기본 로컬 저장을 구분합니다. 별도 저장소는 `GameStorage`의 `load()`·`save()`를 구현해 전달합니다. 비동기 서버 저장은 호스트에서 선로드하고, 동기 스냅샷의 변경을 서버 쓰기 큐로 보내는 어댑터를 붙일 수 있습니다. 사용자 전환 시 React 세션은 사용자 ID를 기준으로 다시 시작합니다. 호스트 서버 인증, 프로필 공유, 커뮤니티 포인트는 현재 범위 밖입니다.

## 일러스트 교체

- 타이틀은 `public/assets/backgrounds/menu.jpg` 파일을 교체합니다. 왼쪽에 제목이 들어가므로 중요한 피사체는 오른쪽에 두면 읽기 쉽습니다.
- 공통 장면은 `public/assets/backgrounds/`, 사건 전용 그림은 `public/assets/events/`에 둡니다. `src/data/art.ts`의 `sceneArt`, `eventArt`에서 각각 장면 ID와 사건 ID를 연결합니다. 특정 장면에서 주인공을 겹쳐 표시하려면 사건 설정에 `character: true`를 추가합니다.
- 초상화는 `public/assets/characters/`의 `male`·`female`과 `early`·`elementary`·`middle`·`high`·`adult` 조합에 해당하는 투명 PNG 파일입니다. 대학과 대학원은 성인 초상화를 사용합니다.
- 직업은 기본적으로 분야별 삽화를 사용합니다. 직업별 전용 파일은 `public/assets/endings/`에 추가하고 `src/data/careers.ts`에서 해당 직업의 `art` 값을 파일 이름에 맞추면 됩니다.
- 전용 그림이 없으면 공통 배경을 사용합니다. 공통 배경 요청도 실패하면 창과 역광을 그린 가벼운 CSS 장면으로 대체합니다. 사건 이미지는 16:9를 권장합니다.

### 현재 일러스트 제작

기본 제공 일러스트 32장은 내장 ImageGen으로 생성하거나 편집한 원본을 정적 게임 에셋으로 정리한 것입니다. 초상화는 사용자가 제공한 교실 예시 이미지에서 인물의 선화와 채색을 참고해 다시 그렸습니다.

| 에셋 | 생성 프롬프트 요지 |
| --- | --- |
| 타이틀 1장 | 늦봄 한국 고교 교실, 바람에 부푸는 얇은 커튼, 오른쪽 창가의 학생 둘, 복숭아색 저녁 하늘, 제목을 위한 어두운 왼쪽 |
| 공통 배경 9장 | 유아 방, 초등 교실, 운동장, 도서관, 노을 교실, 골목, 대학, 연구실, 별이 보이는 꿈속 교실. 구분선 없는 3×3 시트 |
| 주인공 초상화 10장 | 두 주인공의 성장 단계를 담은 2×5 시트. 얇은 선화, 회청색과 옅은 보라색의 셀 채색, 나이마다 다른 시선과 자세, 투명 알파 배경을 적용 |
| 직업 분야 엔딩 6장 | 기술 작업실, 의료 공간, 예술 스튜디오, 도시 사무실, 농장·시장, 천문 연구실. 2×3 시트 |
| 전용 사건 6장 | 졸업 꽃다발, 별빛 창가의 편지, 수능 시험실, 학예회, 야간 열람실, 축제 시연. 2×3 시트 |

섬세한 선과 따뜻한 자연광의 애니메이션 배경 미술을 공통으로 적용했습니다. 나머지 사건은 상황에 맞는 공통 장면을 사용합니다.
